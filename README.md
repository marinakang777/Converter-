Описание
GUI-приложение "Converter" для конвертации валют с использованием внешнего API exchangerate-api.com, сохранением истории конвертаций в формате JSON и управлением версиями через Git.

Технологии

GUI Framework: Python Tkinter 
HTTP Requests: requests библиотека Python
Data Storage: JSON
Version Control: Git
API: exchangerate-api.com (или любой другой с доступным API)

**Как получить API ключ:**
1.  Перейдите на сайт [https://www.exchangerate-api.com/](https://www.exchangerate-api.com/).
2.  Зарегистрируйтесь или войдите в свой аккаунт.
3.  На странице вашей учетной записи найдите раздел "API Key" и скопируйте ваш ключ.
4.  Вставьте полученный API ключ в переменную `API_KEY` в файле `main.py`.

## Использование


1.  **Выбор валют:** В выпадающих списках "From" и "To" выберите валюту, из которой и в которую хотите конвертировать.
2.  **Ввод суммы:** В поле "Amount" введите сумму для конвертации. Сумма должна быть положительным числом.
3.  **Конвертация:** Нажмите кнопку "Convert".
4.  **Результат:** Сконвертированная сумма отобразится в поле "Result".
5.  **История:** Все успешные конвертации будут добавлены в таблицу "History", а также сохранены в файл `history.json`. При следующем запуске истории загружается автоматически.

Примеры использования приложения  Converter:

1.  **Базовая конвертация:**
    *   From: USD
    *   To: EUR
    *   Amount: 100
    *   Ожидаемый Результат: [Примерный результат, основываясь на актуальном курсе]

3.  **Некорректный ввод (сумма):**
    *   From: USD

    *   Amount: -50
    *   Ожидаемый Результат: Предупреждение "Please enter a positive numeric amount."

4.  **Некорректный ввод (выбор валют):**
    *   From: (пусто)

    *   Amount: 100
